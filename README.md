### 🚀 Featured Projects

#### 🚌 CHQ — Coach Hire Quotes
A coach/bus hire marketplace platform connecting travellers who need group
transport with coach hire vendors/suppliers. Full front-end application with
separate client (traveller) and vendor (coach operator) portals — including
an AI-style chat trip planner with drag-and-drop itinerary building, coach
search with interactive maps, booking/reservation flow, and a vendor-side
fleet, quotes, bookings, advertising and finance dashboard.

- **Stack:** Next.js 15 (App Router), React 19, Tailwind CSS 3, Bootstrap 5,
  Framer Motion, Google Maps API / Leaflet, TanStack Table, dnd-kit, Recharts,
  Swiper
- **Live demo:** [chq-next.vercel.app/pages](https://chq-next.vercel.app/pages)

#### 🚗 Carsmart
A static, front-end-only prototype of a car marketplace/auction platform,
hand-coded directly from Figma (100+ pages, no framework, no build step).
Covers the full buying/selling journey — live auctions, "buy it now", quick
sale, wholesale, SmartExchange/SmartConnect/SmartWallet flows — plus vendor
onboarding, KYC, dashboards, and a matching set of 34 transactional email
templates (light/dark variants).

- **Stack:** HTML5, CSS3, Bootstrap 5, vanilla JS + jQuery, AOS, Select2,
  Slick Carousel, Dropzone.js
- **Live demo:** [anash45.github.io/carsmart_v1/pages.html](https://anash45.github.io/carsmart_v1/pages.html)
- **Email templates:** [anash45.github.io/carsmart_v1/email-templates](https://anash45.github.io/carsmart_v1/email-templates/)

#### 💰 Monetars — GPT Rewards Platform
A "get-paid-to" (GPT) rewards platform: a marketing site plus a full member
dashboard where users complete offers, track earnings, climb leaderboards,
claim daily/streak rewards, refer friends, and cash out their balance.
Includes light/dark theme support site-wide and a themed page gallery for
QA'ing every page in both modes.

- **Stack:** Next.js 16 (Pages Router), React 19, Bootstrap 5, jQuery,
  Chart.js, Slick, Flickity, Select2
- **Live demo:** [monetars.vercel.app/page-list](https://monetars.vercel.app/page-list)

#### 💳 PPS Wallet Management
A multi-tenant admin platform for creating, distributing, and managing
digital Apple Wallet and Google Wallet passes (loyalty cards and beyond).
Includes a visual pass template builder (matched to each wallet provider's
real field/layout rules), bulk CSV pass creation/update/voiding with
background job processing, public no-login pass request forms, geofenced
location notifications, multi-language UI, platform-level subscription/plan
management, and a documented public API for company integrations.

- **Stack:** Laravel 12, React + TypeScript via Inertia.js, Tailwind CSS,
  MySQL, Vite, TipTap, Recharts, Google Maps

#### 🗺️ Places Scraper
A Laravel/React tool that, given a place type (e.g. "restaurant") and a
target location (city, region, or whole country), finds and stores every
matching business Google Places knows about in that area — well beyond a
single API call's limit — by recursively subdividing the area into a search
grid, then lets users browse, filter, and export the results as CSV. Handles
location resolution via OpenStreetMap/Nominatim, adaptive grid subdivision
based on result density, stop/resume, stale-job recovery, and a Leaflet map
of live job coverage.

- **Stack:** Laravel, React (Inertia.js), MySQL, Leaflet, Google Places API,
  OpenStreetMap/Nominatim
